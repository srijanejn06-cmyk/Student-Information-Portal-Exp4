About Student Information Portal

Project Overview

This project was developed as a practical demonstration of how a basic web application can be served using Node.js. It presents student-related information in a simple, structured, and visually appealing format.

The purpose of the portal is to display academic and personal details in a clean and professional way while making the fundamentals of web servers easy to understand.

Purpose

To provide a realistic student information display for laboratory learning and demonstration.

Technology

Node.js is used to create the server environment, and the built-in HTTP module is used to handle requests.

Server Setup

The application listens on port 3000 and serves HTML and CSS files from the public directory.

  • Node.js is used to create the web server.
  • The built-in HTTP module handles incoming requests and responses.
  • The server listens on port 3000 and responds to browser requests.
  • HTML and CSS files are served from the public folder.
  • Different routes are used to display the home page and about page.
